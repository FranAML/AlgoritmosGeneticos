Celda 1 — Importación y función objetivo Python original 
import numpy as np
import matplotlib.pyplot as plt

from IPython.display import HTML
from matplotlib.animation import FuncAnimation

def funcion_objetivo(x, y):
    return (
        0.08 * (x**2 + y**2)
        - 5 * np.exp(-((x + 3)**2 + (y + 3)**2) / 2)
        - 3 * np.exp(-((x - 3)**2 + (y - 2)**2) / 2)
    )

La función objetivo representa el problema que el algoritmo genético intenta optimizar. En este experimento se busca minimizar su valor.

Celda 4 — Evaluación y operadores genéticos Python original 
def evaluar_poblacion(poblacion):
    return funcion_objetivo(
        poblacion[:, 0],
        poblacion[:, 1]
    )

def seleccion_torneo(poblacion, fitness, tamano_torneo=3):
    indices = np.random.choice(
        len(poblacion),
        tamano_torneo,
        replace=False
    )

    mejor_indice = indices[np.argmin(fitness[indices])]
    return poblacion[mejor_indice].copy()

def cruza(padre1, padre2):
    alpha = np.random.rand()
    return alpha * padre1 + (1 - alpha) * padre2

def mutacion(individuo, tasa_mutacion=0.15):
    hijo = individuo.copy()

    if np.random.rand() < tasa_mutacion:
        hijo += np.random.normal(0, 0.5, size=2)

    return np.clip(
        hijo,
        LIMITES[0],
        LIMITES[1]
    )

En esta parte aparecen los tres operadores principales utilizados en el experimento: selección por torneo, cruza y mutación. También se utiliza elitismo para conservar las mejores soluciones.
